# Temporal Provenance Benchmark

Reproducible research materials for evaluating temporal-provenance controls in digital evidence.

## Scope

This repository will contain a synthetic benchmark, reproducible analysis code, result tables, checksums, and documentation for the article provisionally entitled *Temporal provenance of digital evidence: an auditable standard for chronological reconstruction in criminal proceedings*.

It does not contain the manuscript, case files, personal data, forensic images, credentials, or material subject to judicial secrecy. The public package will use only synthetic data and properly attributed open research material.

## Publication roadmap

1. Repository foundation and public-scope statement.
2. Synthetic benchmark, reproducibility instructions, and integrity checks.
3. Results, provenance protocol, citation metadata, and release preparation.
4. Archived release through Zenodo, which will mint a DOI for the versioned package.
